# Nexa Digital — المنصة الرقمية الرسمية

موقع وشبكة الخدمات الرقمية لوكالة **Nexa Digital** لتطوير المواقع، التطبيقات، والتصاميم الرقمية.

## 🌟 المميزات الرئيسية
- ⚡ **أداء عالٍ وسريع:** مبني باستخدام أحدث تقنيات Next.js و TypeScript.
- 🌐 **دعم كامل للغتين:** تصميم عصري يدعم العربية (RTL) والإنجليزية (LTR).
- 🎨 **واجهة مستخدم احترافية:** تصميم أنيق ومتجاوب باستخدام Tailwind CSS.
- 📱 **متوافق مع الأجهزة:** تجربة تصفح سلسة على الهواتف والأجهزة اللوحية والحواسيب.

## 🚀 التشغيل محليًا

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل بيئة التطوير
npm run dev
```

افتح المتصفح على [http://localhost:3000](http://localhost:3000)
